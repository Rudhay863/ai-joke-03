A tiny Python program that writes one original one-liner about AI coding agents — the agent that can't explain its own code — to `entry.txt`, for make.fun's "Make the AI judge laugh" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the joke to `out/entry.txt` (no trailing newline). Run it twice and the output is byte-identical.
